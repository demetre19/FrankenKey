# Lessons — the learnings index

The canonical lesson store. Write path: `crew learn <domain> <slug> '<lesson>'` (updates this index and the domain's). Read path: check the domain index below before dispatching or starting work — `crew dispatch-check` refuses on a deterministic prior-art match.

## Domains

- [machinery](machinery/INDEX.md) — domain lessons
